# Digiturno - launcher público del piloto

Esta carpeta contiene únicamente la capa pública para GitHub Pages.

## IMPORTANTE
- Copie estos archivos en la RAÍZ del repositorio `digiturno-prototipo`.
- Puede reemplazar `index.html`, `config.js`, `manifest.webmanifest`, `.nojekyll` y la carpeta `assets`.
- NO borre, reemplace ni copie nada dentro de la carpeta oculta `.git`.
- NO suba a GitHub archivos `.gs`, la base de Google Sheets, secretos, tokens ni credenciales.

El botón `Ingresar` abre la aplicación web de Google Apps Script ya configurada en `config.js`.
